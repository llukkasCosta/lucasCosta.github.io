Projeto em Destaque

PalDex — Sistema de Gerenciamento de Palworld

01

Problema

Jogadores de Palworld precisam organizar informações detalhadas sobre criaturas, recursos, equipamentos e estruturas da base durante a progressão no jogo, sem depender de anotações manuais espalhadas.

02

O que eu fiz

Desenvolvi uma aplicação web full-stack para cadastrar, consultar, atualizar e excluir registros do universo do jogo de forma centralizada e sincronizada em tempo real.

03

Como eu fiz

Estruturei o banco de dados na nuvem utilizando o Firebase para operações CRUD, integrando a interface web com HTML, CSS, JavaScript e TypeScript, além da arquitetura back-end com Node.js, Express, Prisma e Zod.

04

Resultado

Entreguei um sistema funcional dividido em 5 módulos completos de gerenciamento (CRUD), garantindo organização persistente dos dados e validação estruturada em todas as operações.
